# First Step

In this first step, we deployed a simple web application to verify that the Kubernetes cluster was working correctly.

The application includes:

- A Deployment
- A ClusterIP Service
- An Ingress resource
- A ConfigMap used to provide the web content
- A Kustomize configuration to manage and deploy all the manifests together
- A local DNS record in Pi-hole

The goal was to confirm that traffic could flow through Traefik using the hostname:

`miweb.home`

The application can be deployed with:

```bash
kubectl apply -k .
